This repo is the source of my personal portfolio website.

**Tech stack:** [Next.js 16](https://nextjs.org/) (App Router) · React 19 · TypeScript · [Tailwind CSS v4](https://tailwindcss.com/) · [shadcn/ui](https://ui.shadcn.com/) · [Magic UI](https://magicui.design/) · [Motion](https://motion.dev/) · [simple-icons](https://simpleicons.org/)

**Run locally** (Node.js 20.9+ and pnpm):

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000). Other scripts: `pnpm build`, `pnpm start`, `pnpm lint`.

**Editing content**

| What | Where |
| --- | --- |
| Profile, experience, skills, projects, certifications, gallery | [`src/data/resume.tsx`](./src/data/resume.tsx) |
| Blog posts (one `.mdx` file per post) | [`content/`](./content) |
| Photos, logos and project screenshots | [`public/`](./public) |
